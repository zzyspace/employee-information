# 员工中心 · 当前后台布局统一 V2

状态：已于 2026-09-27 按用户确认部署，提交 3030bdd98a4a3bb90f07353ba8a82ef308ee8b1c；本目录仍为独立虚构数据预览，未作为生产文件发布。承接已上线的员工配色和顶部栏，以当前 /invoice 紧凑筛选作为主要参照。

## 本轮方案

- 手机优先：门店常驻第一行，关键词和查询位于第二行；桌面为一行筛选。
- 移除独立刷新和展开筛选入口，查询用于应用条件与重新加载。
- 搜索从输入后自动查询改为点击查询或按 Enter；清除、重置、切换状态继续有效。
- 员工资料 / 回收站 / 全部记录使用统一选中状态，并保留真实权限语义。
- 条目共用姓名/编号、门店/岗位、手机号、证件、时间、操作的相同渲染组件；电脑为表格，手机为卡片，651–980px 为两列卡片。两端显示同样的“查看 / 编辑（或恢复） / 更多”。每页数量在手机端也可见，分页按钮统一为“上一页 / 下一页”。
- 保留当前全宽顶部栏及其控件样式、菜单定位，详情抽屉、证件、历史和编辑主体结构沿用原页面。

门店从折叠改为常驻会多占一行，但省去每次展开筛选的操作。本轮目标是统一操作布局，未声称整体页面高度都缩短。

所有员工、电话、编号、历史和附件均为虚构样本，预览接口仅允许 GET/HEAD，全部写入被拒绝。健康证选填、历史只读和删除/恢复的业务规则保持不变。无真实数据库、线上接口或账户访问。
